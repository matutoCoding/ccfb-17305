# 管道定点测厚三维减薄分析系统

TypeScript + React + WebGPU（WGSL 计算着色器）+ IndexedDB 的浏览器端管道定点测厚与三维减薄分析系统。
内置一套常减压装置塔顶系统演示数据（27 条管线、3300+ 管件、6700+ 测点、2.6 万条读数、4 期测厚、7 处弯头外弧局部减薄、12 行 CSV 坏行），并还原了"测点全打在内弧、外弧漏检导致开车三个月泄漏"的场景。

## 快速开始

```bash
npm install
npm run dev          # 打开终端提示的地址（默认 5173，被占用会自动换端口）
npm run test:core    # 几何定位 / 表面插值 / API570 核心正确性测试（31 项）
npm run build        # 类型检查 + 生产构建到 dist/
```

浏览器建议使用最新版 Chrome / Edge（需开启硬件加速以支持 WebGPU）。
**没有 WebGPU 时不会白屏**：三维页自动降级为 Canvas2D 等轴测交互视图，仍可点测点、看历次读数。

所有管线档案、管件、测点、读数、期次、C 扫、坏行都只存浏览器本机 **IndexedDB**；侧栏可一键重置演示数据。

## 六个页面

1. **管线档案**：按装置 / 单元 / 管线号建档；介质、操作温压、设计压力、材质与许用应力、腐蚀裕量 CA；选 DN + 壁厚等级自动带出外径与名义壁厚（ASME B36.10 表），均可手改。
2. **等轴测建模**：按介质流向一段段录入直管长度/方向、LR/SR/45° 弯头、三通、同心/偏心大小头、法兰、闸阀/止回阀/球阀、盲端；实时校核弯头夹角、走向连接、模型总长 vs 图纸总长（>2% 报错），并自动成图、自动扫出三维。
3. **测厚数据**：测点按"管件 + 距焊口/端面轴向距离 + 钟点"定位；区域语义（弯头内外弧/三通盲端/注水下游）。一期一个 CSV 导入，自动把 **点号找不到 / 读数大于名义壁厚 / 英寸单位 / 解析错误** 的坏行单独隔离；弯头外弧超声 C 扫网格可贴回真实曲面。
4. **三维减薄图**：WebGPU **计算着色器**对管壁顶点做同管件表面距离 IDW 插值；按"剩余壁厚 / tMin"分档、长期/短期速率、两期差值三种云图；外壁透明度、任意管件任意轴向位置剖一刀显示整圈厚度圆环；点球看历次读数。
5. **寿命评估**：B31.3 内压公式 `t=PD/[2([σ]ᵗE+PY)]`（Y=0.4）+ 结构下限得到 tMin；API570 思路算长/短期速率、剩余寿命、半年寿命法则给下次检测日期；每线取最不利管件，一键跳到三维对应点。
6. **检验计划**：自动挑出 RL<2 个检验周期的管件，以及弯头外弧、三通盲端、注水点下游等冲刷部位覆盖不足处，给出可直接落到三维的建议加点；导出 CSV 与带等轴测截图、点位编号的可打印 HTML 测厚任务单。

## 位置与数字一致性（最在意的两点）

- **钟点基准定死**：12 点 = 世界正上方在垂直于流向平面上的投影；观察者站在上游顺流向看，3 点在右侧，`right = normalize(cross(tangent, top))`。竖直管退化到世界 +Z 基准。
- **弯头是精确圆环（圆环参数方程）**，不是近似贴片。`npm run test:core` 用独立的圆环曲面方程 `(ρ−R)² + alongAxis² ≈ r²` 对 41×48 个轴向×钟点位置做校核，最大偏差约 **5e-13 mm**，远小于"偏差 ≤ 管径 2%"（DN200 允许 4.38 mm）；外/内弧与解析 `R±r` 位置偏差 ~1e-13 mm。
- **外弧减薄绝不串到内弧**：插值距离用展开表面度量 `hypot(Δs, r·Δψ_wrap)`，环向包裹，外弧↔内弧必须绕半圈 `πr`（>穿心直线 `2r`），**不穿过管心**；并按 `fittingId` 分区，**不跨焊口/法兰混插**。测试用受控样本对照了表面度量 vs 穿心欧氏距离的串值差异。
- **三维点出的寿命 = 寿命表/导出 CSV = 任务单**：三处都调用同一个 `assessPoint / assessFitting / buildPipelineLifeRows`，并共用 `domain/now.ts` 里同一个评估基准时刻 `NOW`，不存在第二套算法或第二个当前时间。

## 速率与可疑数据口径

- 长期速率 =（首期有效厚度 − 末期有效厚度）/ 实际日历年；短期速率取末两期。
- 后一期比基准厚出超过 UT 重复精度 `UT_TOLERANCE_MM = 0.5mm` 判为**可疑增厚**，不参与速率。
- 控制速率以长期为基准；短期仅在 `>0.2 mm/y 且 >1.4×长期`（确有加速）时才采信，避免两期噪声造成大面积误报。
- 下次检测间隔 = `min(检验周期, RL/2)`；RL≤0 直接判低于最小要求壁厚、建议立即安排。

## 目录结构

```
src/
  domain/        纯领域内核（无 React / DOM 依赖，可被 node 测试直接引用）
    types.ts        全部数据模型
    vec.ts          向量 + 钟点基 clockBasis / 互逆换算
    geometry.ts     走向解析、精确弯头、定位、表面距离
    analysis.ts     表面 IDW、tMin、API570 速率寿命、分档配色
    plan.ts         检验计划/建议加点引擎
    life-table.ts   寿命页与 CSV 导出共用的管线级汇总
    task-sheet.ts   任务单 CSV / 可打印 HTML
    tables.ts       DN-OD-壁厚表、材质许用应力
  data/          IndexedDB 封装、React Store、确定性演示数据、CSV 校验
  viz/           相机/矩阵、参数化网格、WebGPU 渲染器+WGSL、等轴测 Canvas 成图
  components/    Viewer3D（含无 WebGPU 降级）、PointHistory、弹窗/表格等
  pages/         六个页面
scripts/         test-core.ts（31 项正确性测试）、seed-check.ts、plan-check.ts
```

## 演示数据里埋了什么

- 主角管线 `CDU-OH-2001`（DN700 常压塔顶挥发线）的 `F020` LR 弯头：历史测点按事故教训**全部打在内弧**（2025 内弧最薄仍有 8.26mm，结论"合格"）；2026 泄漏后补的外弧点 `T38-O` 仅 **2.07mm（tMin=3.56，58%）**，并有一块 9×11 的外弧 C 扫网格把局部减薄完整贴回曲面。
- 另有 6 处跨装置/注水/排凝线的外弧局部减薄热点。
- 14 处"后期异常增厚"读数会被标为可疑；数据页内置 12 行坏行（未知点号 / 超名义壁厚 / 英寸单位 / 无法解析）。

> 说明：材质许用应力与部分大口径壁厚为工程常用近似值，正式定级请以适用规范版本和设计文件为准。
